# I'm-glad-I-was-this-far-away

Goで実装されたBrainfuckをベースとするプログラミング言語です。

## 特徴

- Go言語で実装
- 8つの水ダソ命令を採用
- 1行につき1命令を記述
- Brainfuckと互換性のある命令の動作
- 30,000個のメモリセル
- 8ビット整数の循環演算
- ループ処理と入出力に対応
- エラー検出機能を搭載
- 自動テストを実装

## 命令一覧

| Brainfuck | IGFA | 動作 |
|---|---|---|
| `+` | よかった | 現在のメモリ値を1増やす |
| `-` | お祭り男！ | 現在のメモリ値を1減らす |
| `>` | アカーン | メモリポインタを右に移動 |
| `<` | この距離で | メモリポインタを左に移動 |
| `.` | 兄さん | 現在のメモリ値を1バイト出力 |
| `,` | 最後の餃子 | 1バイト入力して現在のメモリに格納 |
| `[` | クイヤ | ループ開始 |
| `]` | 浜田の嫁 | ループ終了 |

## インストール方法

インタプリタをビルドするにはGoの開発環境が必要です。

GitHubで公開されたリポジトリをクローンしたあと、プロジェクトのディレクトリで次のコマンドを実行してください。

```bash
go build -o igfa .
```

これにより、`igfa` という実行ファイルが生成されます。

## 使い方

IGFAで書かれたプログラムを実行するには、次のコマンドを使用します。

```bash
./igfa hello_world.igfa
```

実行結果：

```text
Hello World!
```

## 構文仕様

- 1行につき1つの命令を記述します。
- 空行は無視されます。
- 各行の先頭と末尾の空白は無視されます。
- ソースコードの文字エンコーディングにはUTF-8を使用します。
- ソースファイルの拡張子には `.igfa` を使用します。

## プログラム例

以下は、入力された1バイトをそのまま出力するプログラムです。

```text
最後の餃子
兄さん
```

実行例：

```bash
printf 'Z' | ./igfa echo.igfa
```

実行結果：

```text
Z
```

## メモリモデル

本言語では、以下のメモリモデルを採用しています。

- メモリは30,000個のセルで構成されます。
- 各セルには8ビットの符号なし整数（0〜255）が格納されます。
- 値が255
